# Code of Conduct

ProcessFork follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version:

- Be kind. Assume good faith.
- Disagreement is welcome; harassment is not.
- The maintainers reserve the right to remove contributions and ban
  participants who violate this code.

## Reporting

Confidential reports go to the maintainer directly:

- Open a private [GitHub Security Advisory][adv] (works for
  conduct issues too — it's the only built-in private channel
  GitHub provides on public repos).
- Or DM [@manav8498](https://github.com/manav8498) on GitHub.

[adv]: https://github.com/manav8498/processfork/security/advisories/new

GitHub's own ["report abuse"][report] flow is appropriate when the
behaviour is platform-wide.

[report]: https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam
