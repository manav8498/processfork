fork() for AI agents.

Snapshot a live agent — model fast-weights, KV-cache, sandbox filesystem, tool-effect ledger, and reasoning trace — into one content-addressed image. Branch it. Merge it. Push it. Replay it.

Get started View on GitHub

MIT licensed · Rust core · Python & TypeScript SDKs · 200+ tests passing

# 8 ms snapshot of a live agent state
$ pf snapshot --agent-id claude-code --fs-root .
sha256:1c2497b0dc23…
# 12-way fan-out, ~10 ms each (CoW)
$ pf fork sha256:1c24… -n 12 --explore "fix bug"
sha256:3ca3a0ff…
sha256:67711987… (× 12)
# Merge the winner back
$ pf merge sha256:842640c0… --into sha256:1c24…
✓ merged sha256:a41afac1…
# Ship to a teammate
$ pf push sha256:a41afac1… file:///mnt/registry
